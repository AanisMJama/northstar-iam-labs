# Lab 8 — OAuth 2.0 and OpenID Connect (OIDC)

## Objective

Practise a safe test sign-in and understand how OAuth 2.0 authorization and OIDC authentication work together.

## Scenario

Northstar is testing a fictional application. The analyst must review its sign-in flow and permissions without exposing credentials or granting unnecessary access.

## Planned workflow

1. Use a dedicated test application and test account in the lab tenant.
2. Configure an appropriate redirect URI for the test sign-in.
3. Review the authorization code flow and the role of PKCE.
4. Identify the difference between an ID token and an access token without sharing or publishing either token.
5. Review the sign-in result and relevant application settings.
6. Record any tenant or licence limitations.
