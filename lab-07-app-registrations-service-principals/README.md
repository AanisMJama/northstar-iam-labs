# Lab 7 — App Registrations and Service Principals

## Objective

Understand how Microsoft Entra ID represents an application and its tenant-specific service principal. Practise reviewing permissions and access safely.

## Scenario

Northstar’s IT team is assessing a test application before allowing it to access company resources. The analyst must identify the application objects, check permissions, and document any risks.

## Planned workflow

1. Create or inspect a test app registration in a dedicated lab tenant.
2. Find its related service principal under Enterprise applications.
3. Review the application’s owners, users, credentials and API permissions.
4. Check that permissions follow least privilege; do not grant broad consent.
5. Capture redacted screenshots and record any tenant or licence limitations.

## Evidence

Add redacted screenshots after completing the lab. Never include secrets, passwords, tokens, or private keys.
